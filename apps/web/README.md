# RouteOne Web

RouteOne의 지도 탐색, 여행 루트 관리, 공유 루트 탐색 화면을 제공하는 웹 앱입니다.

## 라우팅 구조

라우트는 `src/router/AppRouter.tsx`에서 관리합니다. `/login`을 제외한 모든 화면은 로그인 후 접근할 수 있습니다.

| 경로 | 화면 | 설명 |
| --- | --- | --- |
| `/` | 홈 리다이렉트 | `/home`으로 이동합니다. |
| `/login` | 로그인 | 로그인하고 사용자 세션을 시작합니다. 로그인 상태라면 `/home`으로 이동합니다. |
| `/home` | 지도 | 지도에서 장소를 탐색하고 여행 루트에 장소를 추가합니다. |
| `/my-route` | 나의 여행 루트 | 현재 진행 중이거나 예정된 여행 루트와 일정을 확인합니다. |
| `/notifications` | 알림함 | 도착, 루트, 축제 등 수신한 알림을 확인합니다. |
| `/shared-route` | 공유 루트 | 다른 사용자가 공유한 완료 루트를 탐색하고 좋아요를 표시합니다. |
| `/me` | 내 정보 | 여행 기록과 계정 및 앱 설정 메뉴로 이동합니다. |
| `/me/routes` | 다녀온 루트 | 완료했거나 지난 여행 루트를 모아봅니다. |
| `/me/liked-routes` | 좋아요한 공유 루트 | 좋아요를 표시한 공유 루트를 모아봅니다. |
| `/me/account` | 계정 정보 | 현재 계정 정보를 확인하고 계정을 관리합니다. |
| `/me/language` | 언어 설정 | 앱에서 사용할 언어를 변경합니다. |
| `/me/service-area` | 테스트 지역 설정 | 개발 환경에서 지도에 표시할 Open API 장소 지역을 변경합니다. 운영 환경에서는 `/me`로 이동합니다. |
| `/me/notifications` | 알림 설정 | 축제, 루트, 장소 도착 알림의 수신 여부를 관리합니다. |
| `/me/app-info` | 버전 및 권한 | 앱과 웹 버전, 위치·알림·카메라·앨범 권한 상태를 확인합니다. |

웹 브라우저에서는 `BrowserRouter`를 사용하고, 네이티브 WebView에서 런타임 설정의 `routerMode`가 `hash`이면 `HashRouter`를 사용합니다.
